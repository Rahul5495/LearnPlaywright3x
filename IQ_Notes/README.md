# IQ Notes

## Workflow

1. You ask me a question about any concept
2. I create a `.md` file in this folder explaining it
3. The format follows the style of `Sourcecode_ByteCode_BinaryCode_IQ.md`:
   - A real example as the base
   - A **comparison table**
   - A clear, structured breakdown

## Naming

`ConceptName_IQ.md`

Examples:
- `Sourcecode_ByteCode_BinaryCode_IQ.md`
- `TurboFan_IQ.md`
- `Promise_Callback_IQ.md`
